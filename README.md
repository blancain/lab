# Blancain Lab

Tools and patches by Blancain, each in its own folder.

| tool | what it is | use it |
|---|---|---|
| [Triad](triad/) | Mega Man X, X2 and X3 combined into one 12 MB Cx4 cartridge image, with a debug menu in every game | https://blancain.github.io/lab/triad/ |

Related forks:

- [bsnes](https://github.com/blancain/bsnes): runs Triad's Cx4 SO96 board, on the desktop
  and as a RetroArch core.
- [sd2snes](https://github.com/blancain/sd2snes): the same board on the SD2SNES.

Releases are tagged per tool, for example `triad-v0.1.0`. Everything here is MIT
([LICENSE](LICENSE)) unless a folder says otherwise. Game data is never included; each tool
works from your own dumps.
